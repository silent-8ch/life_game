Frame scan

Loads each spot below in a fixed-size frame, lets the engine draw thirty frames on a fixed timestep, and reads the picture back: which surface holds which columns, by name, across three rows of the real frame. Every other test in this project asserts on what is built. This one asserts on what is drawn, which is where the portal, mirror and sky-lid rules fail.

Run it, copy the JSON, make the change, run it again, and diff the two with node tests/js/scan-diff.mjs before.json after.json. The frame is a fixed size on purpose — two captures taken at different sizes are not comparable, and the diff refuses them.
